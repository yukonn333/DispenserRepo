SmartRation

Descrição do Projeto:
O SmartRation é um sistema desenvolvido em Python com foco na automação e controle da alimentação de animais domésticos. O sistema permite cadastrar horários de alimentação, controlar quantidade de ração e visualizar históricos de dispensação.

Passo a Passo:
Ao executar o codigo uma janela chamada Dispenser aparecera pedindo as informacoes como raça do animal, quantidade de ração e ate mesmo nome do animal, juntamente com o horario que a ração deve ser liberada, ao preencher todos os campos basta apenas esperar a saida de dados e a notificação.

Tecnologias Utilizadas
Python
CustomTkinter
SQLite3
Datetime
Plyer
